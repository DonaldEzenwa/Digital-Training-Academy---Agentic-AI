## Course sequence

Follow the GitHub `week3` folder in order:

1. Introduction to Python: programming concepts, Python setup, Hello World, keywords, and identifiers.
2. Variables, literals, and constants: data types, type conversion, and date/time values.
3. Programming building blocks: operators, conditions, loops, functions, scope, exceptions, and collections.
4. Worked examples: combine the concepts in runnable programs.
5. Exercises and solutions: practise independently before checking the reference answers.
