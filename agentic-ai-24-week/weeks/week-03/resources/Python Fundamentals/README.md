# Python Fundamentals

## eCOMMart AI Squad

This beginner course introduces Python through e-commerce examples. No prior programming experience is required.

## Course structure

```text
week3/
|-- 01 - Introduction to Python
|-- 02 - Variables, Literals and Constants
|-- 03 - Programming Building Blocks
|   |-- A - Operators and Conditions
|   |-- B - Loops
|   |-- C - Functions and Scope
|   `-- D - Collections
|-- 04 - Worked Examples
|-- 05 - Exercises
`-- Cohort 1 - demo through Cohort 4 - demo
```

## Learning path

Complete the numbered lessons in order. The downloaded files use this sequence:

- `001` to `005`: programming, Python, installation, Hello World, keywords, and identifiers.
- `006` to `009`: variables, literals, data types, type conversion, and dates.
- `010` to `013`: operators, conditions, and list comprehensions.
- `014`: while loops and user input.
- `015` to `019`: functions, arguments, scope, and exceptions.
- `020` to `025`: lists, dictionaries, tuples, sets, booleans, and collection methods.

## Practice materials

- [Worked examples](week3/04%20-%20Worked%20Examples/worked_examples.md) combine the lesson concepts in runnable programs.
- [Exercises](week3/05%20-%20Exercises/exercises.md) provide independent practice.
- [Solutions](week3/05%20-%20Exercises/solutions.md) should be opened after attempting the exercises.
- The cohort demo folders contain Python examples from the course sessions.

## Recommended workflow

1. Read one lesson and type the examples yourself.
2. Run the code and inspect the output.
3. Adapt each example to products, prices, customers, or orders.
4. Complete the exercises before reviewing the solutions.

All examples use the eCOMMart B2B e-commerce platform as their working context.
