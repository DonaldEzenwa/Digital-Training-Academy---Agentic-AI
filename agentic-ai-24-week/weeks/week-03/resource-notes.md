# Week 03 Resource Notes - Python Fundamentals

## Official topic

Python Fundamentals

The Week 3 GitHub material is a beginner Python course built around the eCOMMart B2B e-commerce platform. It assumes no prior coding experience and moves from Python setup to small, complete programs.

## Key concepts

- Programming basics, Python installation, VS Code workflow, keywords, and identifiers.
- Variables, constants, literals, primitive data types, `None`, `NaN`, and type conversion.
- Dates and time values.
- Arithmetic, comparison, logical, and other Python operators.
- `if`, `elif`, and `else` decision-making.
- `for` and `while` loops, including user input.
- List comprehensions.
- Functions, default and keyword arguments, `*args`, `**kwargs`, nested statements, and LEGB scope.
- Exception handling.
- Lists, dictionaries, tuples, sets, booleans, and common collection operations.
- Worked examples and graduated exercises.

## Practice plan

1. Install Python and confirm that a simple script runs from the terminal or VS Code.
2. Create small values for products, prices, quantities, and order status.
3. Use conditions to validate an order and loops to process multiple products.
4. Extract repeated logic into functions and handle invalid input with exceptions.
5. Store product and order data in appropriate collections.
6. Complete the worked examples, then attempt all exercises without copying the solutions.

## My summary

Python fundamentals are the building blocks for later automation and agentic AI work. This week focuses on turning data into useful programs: represent information with variables and collections, make decisions with conditions, repeat work with loops, and organize behavior with functions. The eCOMMart examples make those ideas concrete through familiar product and order workflows.
