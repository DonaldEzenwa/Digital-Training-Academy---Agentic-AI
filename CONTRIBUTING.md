# Contributing to Digital Training Academy - Agentic AI

Thank you for helping improve Donald Ezenwa's Agentic AI learning guide. This repository organizes original course links, personal notes, and practice resources for a 24-week program.

## Before You Start

1. Read the root [README](README.md) and the [24-week overview](agentic-ai-24-week/README.md).
2. Choose a week under `agentic-ai-24-week/weeks/week-XX/`.
3. Review that week's `README.md` and `resource-notes.md` before editing.
4. Do not mark a resource as reviewed or completed until you have opened and studied it.

## Getting Started

Clone the repository and create a working branch:

```bash
git clone https://github.com/DonaldEzenwa/Digital-Training-Academy---Agentic-AI.git
cd Digital-Training-Academy---Agentic-AI
git checkout -b update-week-03-resources
```

Make focused changes, then commit and push them:

```bash
git add .
git commit -m "Update Week 03 learning resources"
git push origin update-week-03-resources
```

Open a pull request against `DonaldEzenwa/Digital-Training-Academy---Agentic-AI:main`.

## Adding Resources

For each resource, record:

| Field | Requirement |
|---|---|
| Title | Use the official course or material name. |
| Type | Course, reading, video, repository, lab, or other appropriate type. |
| Link | Link to the original source. |
| Status | Use `Not started`, `In progress`, `Completed`, `Reviewed`, or `Needs access`. |
| Last reviewed | Add a real date in `YYYY-MM-DD` format when the link or content was checked. |

Prefer original links. Do not copy restricted course content, private materials, or copyrighted lessons into the repository without permission.

## Weekly File Checklist

Each active week should contain:

### `README.md`

- Official week title, when verified.
- Current status.
- Source and learning-platform links.
- Learning objectives based on the source material.
- A practical workflow or checklist.
- A link to `resource-notes.md`.

### `resource-notes.md`

- Official topic.
- Key concepts.
- Notes for each source.
- Questions and open items.
- A personal summary in the learner's own words.

Weeks without supplied materials should retain the template and clearly state that the content is awaiting review.

## Updating the Roadmap

Update [agentic-ai-24-week/ROADMAP.md](agentic-ai-24-week/ROADMAP.md) when a week's official topic or status is confirmed. Do not invent topics or learning outcomes.

## Quality Rules

1. Keep links accurate and use the repository's actual paths.
2. Keep source material separate from personal notes.
3. Use accurate status labels and real review dates.
4. Preserve the existing week numbering and folder structure.
5. Keep changes focused on the relevant week or documentation issue.
6. Check Markdown links and diagnostics before opening a pull request.

## Questions

For unclear ownership, access, or curriculum details, record the question in that week's `resource-notes.md` rather than guessing.
